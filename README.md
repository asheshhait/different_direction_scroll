# different_direction_scroll
# 🎯Day14 of  30 Days of GSAP Challenges

Welcome to my **30-day GSAP animation challenge**! This project is a creative exploration of the **GreenSock Animation Platform (GSAP)**, where I’ve built dynamic and visually appealing web animations using **HTML**, **CSS**, and **GSAP**. The images used throughout the project are sourced from [Unsplash](https://unsplash.com/).

---

## 🚀 Project Highlights

- 🔁 **2 Different Vertical Sliders**  
  Two vertically stacked sliders that animate in **opposite directions** when the user scrolls.

- ✨ **Smooth GSAP Animations**  
  Leveraging GSAP's scroll-triggered animations for a smooth and responsive feel.

- 🖼️ **High-Quality Imagery**  
  Images are pulled from Unsplash to bring each slide to life.

---

## 🛠️ Technologies Used

- **GSAP** (GreenSock Animation Platform)
- **HTML5**
- **CSS3**
- **JavaScript (vanilla)**
- **Unsplash ** (for images)
